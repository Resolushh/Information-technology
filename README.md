# 💻 Информационные технологии

> Репозиторий, посвящённый изучению информационных технологий и их применению на практике.

**Добро пожаловать!** 👋

Этот проект создан для того, чтобы собрать и систематизировать материалы по предмету «Информационные технологии», включая теоретические сведения, практические работы и различные учебные задания.
